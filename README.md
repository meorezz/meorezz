## Featured projects

### AI Rental Discovery

An AI-powered rental search service built with Node.js, Express, Firebase Genkit, and Google Cloud Run. It interprets search requests, finds Google Places candidates, scores listings by factors such as distance, price, and vibe, and streams ranked recommendations with explanations. I also built a Python pipeline to scrape and geocode around 30 rental listings near UTM Skudai for price enrichment.

### Borneo Endangered Language Learning App

A cross-platform Flutter app to help preserve endangered languages in Sabah and Sarawak. It combines vocabulary practice and AI-powered pronunciation feedback with an offline-first SQLite experience, Supabase sync, and community-submitted words and recordings.

### DerivIQ

An AI-powered trading platform with a stock research agent that analyzes news, financials, and market metrics, alongside a decision agent that produces Buy, Hold, or Sell recommendations. I developed its Next.js and React dashboard, streaming AI chat, Finnhub market-data panels, behavioral insights, and secure Supabase-backed API routes.

### NASA Terrain Storytelling App

An Angular storytelling experience that visualizes global terrains and landscapes using official NASA data, with responsive, data-driven UI components.

### Anti-double-parking system

Built an Arduino-based system that won first place at the My Digital Maker TeenTech Prizes.
